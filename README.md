# dotMDCUTTER ✂️📄

**dotMDCUTTER** — утилита и графическое приложение для пиксель-в-пиксель нарезки файлов Markdown (`.md`) на изображения размером **320×240** (или **240×320**).

Идеально подходит для:
- Чтения заметок и шпаргалок на умных часах, фитнес-браслетах и портативных медиаплеерах.
- Дисплеев микроконтроллеров **ESP32**, **Arduino**, **Raspberry Pi Pico** (ILI9341, ST7789 и др.).
- Электронных книг и устройств с маленькими экранами.

---

## Особенности

- 🧠 **Умная пагинация без срезанных строк**: Никакого горизонтального разрезания текста пополам. Слова переносятся с учетом границ, а элементы распределяются строго по высоте страницы.
- 🎨 **Красивые цветовые темы**:
  - `dark` (по умолчанию) — контрастная темная тема для OLED и TFT экранов.
  - `light` — чистый бумажный стиль.
  - `eink` — монохромный сверхконтрастный черно-белый режим.
  - `amber` — ретро янтарный терминал.
  - `matrix` — классический хакерский зеленый терминал.
- 🔤 **Поддержка полного Markdown**:
  - Заголовки `# H1`, `## H2`, `### H3` с цветными акцентами.
  - Оформление текста: **жирный**, *курсив*, ***жирный курсив***, `встроенный код` с плашками, ~~зачеркивание~~.
  - Блоки кода с карточками, рамкой и языковым бейджем (например, `PYTHON`, `CPP`).
  - Маркированные (`•`) и нумерованные (`1.`, `2.`) списки с аккуратным висячим отступом.
  - Цитаты `> ` с вертикальной полосой выделения.
  - Принудительные разделители страниц: `---page---`, `---break---`, `<!-- pagebreak -->`, `\newpage` или горизонтальные линии `---` (при ключе `--hr-pagebreak`).
- 🖼️ **Форматы экспорта**: `PNG` (четкий текст без артефактов), `JPG` (сжатие) и `BMP` (24-bit RGB для микроконтроллеров без JPEG декодера).
- 💻 **Два режима работы**:
  - **CLI** (консоль) — для скриптов, терминала и пакетной обработки.
  - **GUI** (интерфейс на PyQt6) — интерактивное окно с живым предпросмотром страниц в масштабе 1x/2x/3x, выбором тем, ползунком размера шрифта и удобным перелистыванием.

## Быстрый старт

### Запуск GUI (графического интерфейса)

```bash
# Запустить графический предпросмотр
python3 -m dotmdcutter --gui

# Или передать файл сразу:
python3 -m dotmdcutter sample.md --gui
```

В интерфейсе доступно:
- Перетаскивание (Drag & Drop) любого `.md` файла в окно.
- Выбор разрешения (320×240 альбомная или 240×320 портретная).
- Ползунок размера шрифта (9px — 28px) с **мгновенным** перерасчетом страниц.
- Переключение тем и форматов в реальном времени.
- Навигация стрелками на клавиатуре (`←` / `→`).
- Кнопка **«Сохранить все страницы»** с выбором папки.

### Использование в консоли (CLI)

```bash
# Нарезать файл на страницы 320x240 в формате PNG (в папку sample_slices/)
python3 -m dotmdcutter sample.md

# Указать папку вывода:
python3 -m dotmdcutter sample.md -o my_pages/

# Выбрать тему (dark, light, eink, amber, matrix) и формат (png, jpg, bmp):
python3 -m dotmdcutter sample.md -t amber -f bmp

# Портретная ориентация (240x320):
python3 -m dotmdcutter sample.md --orientation portrait

# Настроить размер шрифта и скрыть номер страницы внизу:
python3 -m dotmdcutter sample.md --font-size 14 --no-footer
```

### Все флаги командной строки

| Параметр | По умолчанию | Описание |
|---|---|---|
| `input_file` | — | Путь к файлу Markdown (`.md`) |
| `-o, --output` | `<имя>_slices/` | Папка для сохранения изображений |
| `-w, --width` | `320` | Ширина картинки в пикселях |
| `-H, --height` | `240` | Высота картинки в пикселях |
| `--orientation` | `landscape` | Быстрый выбор: `landscape` (320×240) или `portrait` (240×320) |
| `-t, --theme` | `dark` | Тема: `dark`, `light`, `eink`, `amber`, `matrix` |
| `-f, --format` | `png` | Формат: `png`, `jpg`, `bmp` |
| `-s, --scale` | `1` | Множитель разрешения HiDPI: `1` (320×240), `2` (640×480), `3` (960×720) с сохранением идентичной верстки |
| `--font-size` | `13` | Базовый размер шрифта (в пикселях) |
| `--margin-x` | `10` | Горизонтальные поля |
| `--margin-y` | `8` | Вертикальные поля |
| `--no-footer` | `False` | Скрыть номер страницы `1/N` внизу |
| `--no-sharpen` | `False` | Отключить микро-фильтр четкости контуров текста |
| `--hr-pagebreak` | `False` | Считать каждую линию `---` разделителем страниц |
| `--prefix` | `page_` | Префикс имен файлов (`page_001.png` и т.д.) |
| `--gui` | `False` | Открыть графический интерфейс предпросмотра |
